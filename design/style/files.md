# Files

- Each entry point is a `.js` file in `src/` with a `.d.ts` next to it:
  `index` for sync and `async` for async (see
  [Entry points](../components/entry-points.md)).
- Tests are next to the code they test, in JS (`*.test.js`).
- `benchmark/` isn't committed. The benchmarks in `benchmark/benchmarks/`
  are kept up to date, and the ones in `benchmark/claude/` were written for
  one-off investigations.
- `scratch/` isn't committed. It's for trying things out.
